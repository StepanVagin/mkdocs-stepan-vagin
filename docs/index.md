## How this documentation is organized

The docs follow the stages of a typical user journey:

- **Getting Started** — install the project and run your first correction in under 5 minutes.
- **How to Use** — task-oriented guides for the web interface, Python API, and CLI.
- **Data Pipeline** — how to download, process, and extend the training corpora.
- **Models** — how each model works and how to train a custom one.
- **Architecture** — system design decisions and project layout.
- **Contributing** — how to add parsers, follow code style, and open a PR.
- **Reference** — complete API and CLI flag tables.

If you are new, start with [Quick Demo](getting-started/quick-demo.md).  
If you want to integrate the checker into your code, go to [Python API](how-to/python-api.md).  
If you want to understand the internals, go to [System Design](architecture/design.md).
